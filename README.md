# スキーゲーム：Stars and Coins

## ゲームの概要

プレイヤーを左右に操作して、コース上の木や崖を避けながら進む、文字表示のスキーゲームです。コインやスターを集めてスコアを伸ばし、できるだけ長い距離を滑ることを目指します。

## 動作環境

- OS：Windows
- Python：3.14.5
- 必要なライブラリ：windows-curses

## インストール方法

1. Python 3.14.5をインストールします。
2. このリポジトリをダウンロードまたはクローンします。
3. リポジトリのフォルダーをターミナルで開き、次のコマンドで必要なライブラリをインストールします。

```powershell
py -m pip install windows-curses
```

## 起動方法

リポジトリのフォルダーをターミナルで開き、次のコマンドを実行します。

```powershell
py "w13~15sky.py"
```

## 操作方法

- 左矢印／右矢印：進行方向を左右に切り替えます。
- Space：ゲーム開始、または一時停止・再開をします。
- 開始前にN：NORMAL、H：HARDを選びます。
- ゲームオーバー後にR：ゲームを再開します。
- Q：ゲームを終了します。

木（A）やコース外の崖（*）にぶつかるとゲームオーバーです。スター（+）を取るとボーナス点と速度上昇効果を得ます。コイン（@）を取るとスコアが加算され、スターによって上がった速度が低下します。距離に応じてレベルと速度が上がります。

## 追加・改良した機能

第12回のスキーゲームをもとに、次の4つを追加・改良しました。

1. **スターの追加**：コースにスターを追加しました。取ると加速します。
2. **コインの得点が倍増**：最初のコインは100点で、取るたびに次のコインの得点が2倍になります。
3. **スターで500点加算**：スターを取ると、従来の加速に加えて500点が入ります。
4. **コインで加速を1段階戻す**：スターで加速しているときにコインを取ると、加速が1段階戻ります。加速していないときは速度に影響しません。

## 既知の問題・制限事項

ターミナルの表示領域が幅64文字・高さ21行未満の場合はプレイできません。画面が小さい場合はターミナルを広げてください。Windowsでは起動前に`windows-curses`のインストールが必要です。その他の不具合は未確認です。
